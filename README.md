# よびごえの館 〜森の奥の わかれ道〜

嵐の夜、森で迷って逃げこんだ古い洋館。扉は閉ざされ、どこかで だれかが **あなたの名前** をよんでいる——。
1〜4人で協力して謎を解き、館から脱出する **超ホラー** 謎解きブラウザゲームです。ストーリー・謎・絵・音はすべてオリジナル（SVG と Web Audio でその場で生成）。

**情報が非対称**：みんなのスマホには **それぞれ別の部屋** が映ります。答えのヒントは仲間の画面にあるので、声をかけあって解きます。ひとりで遊ぶときは全部の部屋を行き来できます。
ひとり1台のスマホ（iPhone Safari / Android）や PC で遊べます。P2P（PeerJS）でホストの端末が進行役になり、サーバーは使いません。

## 遊び方（かんたん）
1. 部屋を作って（または「ひとりで入る」）、ニックネームを入れる。「何か」は その名前でよびかけてきます。
2. 部屋のものを タップして しらべる。鍵（🔒）のかかったものは、ほかの部屋の手がかりで開く。
3. 時間がたつほど「気配」が上がる。まちがえる・ヒントを使うと上がり、謎を解くと下がる。100 になると つかまる。
4. 幕のおわりに「何か」がやってくる：**かくれる**（長押しで息を止める）→ **にげる**（左右の足を交互に連打）。
5. 地下室の祭壇で、集めた名前のかけらを並べて「あの子」の名前をよび、みんなで ろうそくを守れば 夜明け。
6. つかまっても、チェックポイントから やりなおせます（解いた謎はそのまま）。

## 内容
- 6部屋（玄関ホール／書斎／子ども部屋／台所／礼拝堂／地下室）・3幕・10の謎。答え（時刻・暗証番号・メロディ・色・名前など）は毎回ランダム。
- 日記のページで少しずつ物語がわかり、エンディングで真相＋ひとつの「オチ」。
- 部屋の分け方：1人＝全部屋／2人＝[玄関・台所]・[書斎・子ども部屋・礼拝堂]／3人＝[玄関・台所]・[書斎・礼拝堂]・[子ども部屋]／4人＝1人1〜2部屋。地下室は全員共通。抜けた人の部屋は自動でほかの人へ。
- 🐻 ふーさん：3段階のヒント（3段目は答え。気配＋4）。

## 恐怖演出
懐中電灯（指の位置を照らす暗闇）、フィルムグレイン、ちらつき、雨・風・低音ドローン・気配で速くなる心音（Web Audio）／
ジャンプスケア（顔＋スティンガー＋画面ゆれ＋バイブ）、画面端に立つ人影、ひとりでに開く扉、文字が書きかわる、黒電話が鳴る、名前のささやき（音声合成）、窓の手形、ノック・足音・笑い声、停電、鏡、など。
幕ごとに強くなり、みんなのスマホで同時に起きる演出と、ひとりにだけ起きる演出があります。
- スタート前に注意表示。⋯ メニューで「びっくり演出」つよめ／ふつう／ひかえめ、音のオン／オフ。
- 激しい点滅なし（3Hz を超える明滅はしない）。流血・グロ表現なし。

## ファイル
- `index.html` … 画面とスタイル
- `core.js` … 共通の定数・タイミング・小道具・あそびかた
- `audio.js` / `bgm.js` … 効果音・環境音（Web Audio で合成）、ささやき（speechSynthesis）
- `art.js` … 部屋・顔・人影などの SVG 生成
- `fx.js` … 恐怖演出（ジャンプスケア・人影・停電など）、懐中電灯・グレイン
- `host.js` … ホスト側のゲーム進行（authoritative、各端末には自分の部屋の情報だけ送る）、演出スケジューラ
- `net.js` … PeerJS の通信（ホスト受付・参加者・再接続）
- `ui.js` … 画面の描画・謎のUI
- `app.js` … ボタン操作・タイトル・全体の流れ（最後に読み込む）
- `logic.js` … 部屋・謎・気配・チェイス・チェックポイントのエンジン（DOMに依存しない、Node でも動く）
- `config.js` … STUN/TURN の設定（`HM_CONFIG.iceServers`）
- `vendor/` … peerjs, qrcode
